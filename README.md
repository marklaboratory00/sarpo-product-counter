# Sarpo — бот пересчёта остатков

Телеграм-бот для пересчёта платьев по размерам (XL/L/M/S/XS) в филиалах.

## Как это работает
- **Администратор** (только он) загружает каталог: отправляет боту фото с подписью
  `22101 Anor gullari - oq rang`. Первое слово подписи = артикул, остальное = название.
- **Сотрудник** жмёт `/start`, выбирает филиал и по очереди вписывает остатки
  (`2 3 1 0 4`) для каждого товара. Прогресс и автосохранение — можно закрыть и продолжить.
- В конце админ командой `/export` получает Excel: `Филиал | Артикул | Название | XL | L | M | S | XS | Дата`.

Филиалы: Sarpo Sergeli, Sarpo Yunusobod, Sarpo General. Каталог общий на все три.

## Команды администратора
- `/list` — список загруженных товаров
- `/undo` — удалить последний товар
- `/clear` — очистить весь каталог
- `/done` — сообщить, что каталог готов
- `/report` — статус: сколько посчитано по каждому филиалу
- `/export` — выгрузить Excel с остатками
- `/newcount` — начать новый пересчёт (обнулить остатки, каталог остаётся)

## Переменные окружения (Railway → Variables)
- `BOT_TOKEN` — токен от @BotFather
- `ADMIN_ID` — твой числовой Telegram ID (узнать: @userinfobot)
- `DB_PATH` — `/data/bot.db` (нужен постоянный диск, см. ниже)

## Постоянный диск (важно!)
Railway → сервис → **Volumes** → New Volume → Mount path `/data`.
Без диска каталог и остатки сотрутся при каждом обновлении.

## Запуск
Бот работает через long polling — домен/webhook не нужны.
Start command: `python bot.py` (обычно подхватывается из Procfile).
